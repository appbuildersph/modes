# Working notes for the learning-modes research

These are the research notes behind `docs/research/learning-modes-evidence.md`. The report supersedes them: where a note and the report disagree, trust the report.

- `kalma.md`, `pakinig.md`, `hakbang.md`: evidence per mode, with competency tables.
- `ph_context.md`: Philippine context. Its last section, "Coordinator corrections", overrides earlier statements in that file about the MATATAG rollout, PISA, TIMSS and RA 12027.
- `apps_and_sources.md`: existing apps and research websites.
- `ai_and_speech.md`: AI tutor and speech technology papers.
- `competency-map.md`: Grade 1 to 6 competency codes, domains and tiers, generated from `src/curriculum/`.
- `verified_abstracts.md`: Crossref citation and abstract (from Crossref or OpenAlex, copied as published) for every DOI in the notes. Numbers in the report come from these abstracts.

"Hiyang" in the notes is the mockup's working name (`mockups/hiyang/`). The project name is still undecided (`CLAUDE.md`).
