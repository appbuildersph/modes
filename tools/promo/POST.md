# Social post (X or LinkedIn), attach sibol-promo-en-9x16.mp4 (or the 16:9 file on LinkedIn)

We built SIBOL (Student-centered Inclusive Bilingual Offline Learning) for the #AppBuildersPH Hackathon 2026 (Local AI): a math tutor for Filipino Grade 4-6 learners that keeps working when the internet doesn't. The tutor's AI, Gemma 4 E2B, runs on a laptop in the room through LM Studio, not on a cloud AI API. With the Wi-Fi off, it still answers in English, Tagalog or Taglish. Three learning modes, Kalma, Pakinig and Hakbang, change both the screen and how the AI replies. Built with help from AI coding tools. @cognition @DevinAI https://github.com/appbuildersph/modes
